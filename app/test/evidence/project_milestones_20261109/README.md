# Native Projektmeilensteine – 09.11.2026

In der geöffneten Projektmappe steht bei freigeschaltetem Modul das Register
**Meilensteine** bereit. Es zeigt aktuelle Ziele mit Termin, Verantwortlichem,
manuellem Status und vollständiger Änderungshistorie. Eine frühere Zuordnung
bleibt auch bei verändertem Projektteam erhalten; die Oberfläche lädt dafür
keine fremden Personenstammdaten nach. Historische Texte, einschließlich
Randabständen, Unicode sowie CR/LF, bleiben unverändert.

Vor Zugriff und Speicherung werden Projektkontext und Rechte frisch geprüft.
Eine verlorene Antwort wird mit exakt demselben Auftrag wiederholt. Beim
Wiederöffnen während einer laufenden Anfrage teilen sich beide Ansichten deren
Ergebnis; eine inzwischen eingetroffene Bestätigung wird als ursprüngliche
Quittung übernommen. Es entsteht dadurch keine zweite Anlage. Abmeldung,
Projekt-/Serverwechsel oder Rechteentzug geben keine fremden Inhalte frei.

Die Statusänderung löst keine Aufgabe, Planung, Zahlung oder Abnahme aus.
Die neue Funktion verändert keine vorhandenen Offline-Speicherformate.

Der [Prüfnachweis](manifest.json) enthält Quell-/Fixturehashes, genaue Befehle,
96 bestandene Regressionen, beide erfolgreich wiederholten Race-Reihenfolgen,
die zusätzliche echte Projekt-Navigations-/HTTP-/CRLF-Prüfung bei390px und die
abschließende App-Analyse ohne Befund. Sämtliche früheren Fehlversuche bleiben
in ihren komprimierten Rohprotokollen erhalten. Der zusätzliche HTTP-Nachlauf
ersetzt die zuvor schmalere Ausführung desselben Falls; Testzahlen werden nicht
als unabhängige Fälle addiert. Eine Veröffentlichung oder Geräteabnahme ist
mit diesem Nachweis nicht verbunden.
